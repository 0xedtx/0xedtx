### 📌 Notas Rápidas de Git (Cheat Sheet)
*Sempre esqueço, então deixo aqui:*

* **Criar nova branch:** `git checkout -b nome-da-branch`
* **Salvar alterações:** `git add .` + `git commit -m "o que eu fiz"`
* **Atualizar o repositório local:** `git pull origin main`
* **Enviar para o GitHub:** `git push origin nome-da-branch`
